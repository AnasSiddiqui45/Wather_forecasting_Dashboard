## Weather Forecasting Dashboard (Power BI)

This project is an interactive Weather Forecasting Dashboard built using Power BI. The data is fetched in real time from the web using a weather API, ensuring accurate and up-to-date information. The dashboard analyzes key weather metrics such as temperature, Air Quality Index (AQI), humidity, and other environmental conditions across multiple cities.

The API data was connected to Power BI using web data connectors and transformed using Power Query for cleaning and structuring. Data modeling techniques were applied to create relationships, calculated columns, and DAX measures for meaningful analysis.

The dashboard includes interactive visuals such as KPI cards, line charts, and city-wise comparisons, allowing users to track trends, monitor environmental conditions, and make data-driven decisions. Dynamic filters and slicers improve usability and enable detailed exploration.

This project demonstrates skills in API integration, web data extraction, data transformation, data modeling, DAX, and dashboard design in Power BI.
